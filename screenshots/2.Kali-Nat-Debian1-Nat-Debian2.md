# Построить и настроить следующую сетевую схему:

```text
Kali ← NAT1 ← debian1 ← NAT2 ← debian2
```

## Схема:

                Internet
                    │
             VirtualBox NAT
                    │
                Kali Linux
          eth0: 10.0.2.15
          eth1: 192.168.10.1
                    │
         ─────────────────────
                    │
                Debian1
          enp0s8: 192.168.10.2
          enp0s9: 192.168.20.1
                    │
         ─────────────────────
                    │
                Debian2
          enp0s8: 192.168.20.2
