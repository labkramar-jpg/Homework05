# 🔹 1. Утилита `ip`

Используется для просмотра и настройки сетевых интерфейсов, IP-адресов и маршрутов.

## Пример команды

```bash
ip addr show
```

```output
1: lo: <LOOPBACK,UP,LOWER_UP>
    inet 127.0.0.1/8

2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP>
    inet 10.0.2.XX/24 brd 10.0.2.255
    inet6 fd17:xxxx:xxxx::1/64
    inet6 fe80::xxxx/64
```
```output
Пояснение:
127.0.0.1/8 - используется для локальных проверок

eth0 — сетевой интерфейс
UP — интерфейс активен
inet 10.0.2.XX/24 — IP-адрес устройства
10.0.2.255 - broadcast
```

# 🔹 2. `ping`

```bash
ping google.com
```

```output
PING google.com (142.250.130.113) 56(84) bytes of data.
64 bytes from zq-in-f113.1e100.net (142.250.130.113): icmp_seq=1 ttl=255 time=9.67 ms
64 bytes from zq-in-f113.1e100.net (142.250.130.113): icmp_seq=2 ttl=255 time=10.6 ms
```

```output
Пояснение:
узел доступен
time=18 ms — задержка ответа
чем меньше время, тем лучше соединение
```

# 🔹 3. `traceroute`

```bash
traceroute google.com
```

```output
1  192.168.1.1
2  10.10.0.1
3  ...
```

```output
Показывает промежуточные маршрутизаторы, через которые проходит трафик
первый hop - локальный роутер
далее сеть провайдера
затем интернет-маршрут
```

# 🔹 4. `ss`

```bash
ss -tn
```

```output
State  Recv-Q Send-Q Local Address:Port   Peer Address:Port
ESTAB  0      0      10.0.2.XX:52344      142.250.74.14:443
```

```output
ESTAB — соединение установлено
10.0.2.XX — мой компьютер
142.250.74.14 — удалённый сервер
443 — защищённый HTTPS порт
```

# 🔹 5. `netcat`

```bash
nc -zv google.com 443
```

```output
DNS fwd/rev mismatch: google.com != zq-in-f100.1e100.net
DNS fwd/rev mismatch: google.com != zq-in-f101.1e100.net
...
google.com [142.250.130.100] 443 (https) open
```

```bash
Команда nc -zv google.com 443 показала, что сервер google.com доступен по защищённому HTTPS-порту 443
```
